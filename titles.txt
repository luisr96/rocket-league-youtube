# YouTube title patterns. For each video, the lines whose conditions fit are
# collected and one is picked at random (not one used in the last 5 uploads).
# Add, remove or change lines freely. Lines starting with # are ignored.
#
# Placeholders (written exactly like this, in curly brackets):
#   {PLAYER}  the player's name in capitals, e.g. ATOW
#   {RANK}    the rank, e.g. SSL (left out when unknown)
#   {MODE}    the mode, e.g. 2v2
#   {GOALS} {ASSISTS} {SAVES} {SHOTS} {POINTS}   the player's totals over both games
#   {WINS}    games won (0-2)
#   {FASTEST} the player's fastest goal, in kph
#
# Conditions (optional), in square brackets at the start of a line; with several,
# separated by commas, all must be true. Totals are over both games:
#   wins, losses (0-2), goals, assists, saves, shots, points,
#   overtime (games that went to overtime, 0-2), fastest (fastest goal, kph),
#   comebacks (games won after being 3 or more goals behind, 0-2)
#   Operators: =  !=  >  >=  <  <=
#   e.g.  [wins=2, goals>=4] {PLAYER} Drops {GOALS} Goals in {RANK} {MODE}!
# A line without conditions can be picked for any video. A line whose conditions
# fit counts 3 times in the draw (special_title_weight in config.toml).
# YouTube allows titles up to 100 characters.
#
# Style (from the channel this is modelled on): the name in capitals, one strong
# word, "in Ranked..." or "in Rocket League", the rank and mode in brackets at the end.
